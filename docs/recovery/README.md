# Trove rebuild record

Design and verification documents from the rebuild of Trove into the `trove-core`
monolith. Source comments and ADRs cite these files by name, so they are kept here. The
rebuild's session logs and tooling are kept in a private archive and are not published.

| File | What it is |
|---|---|
| [`01-FINDINGS.md`](01-FINDINGS.md) | Verified findings dossier on the pre-rebuild codebase, by area, with file:line. |
| [`04-REVIEWS-AND-SCOPE.md`](04-REVIEWS-AND-SCOPE.md) | Senior reviews and the recommended scope cut. |
| [`06-COLLAPSE-PLAN.md`](06-COLLAPSE-PLAN.md) | Monolith collapse plan (`trove-core`). |
| [`06-PROGRESS.md`](06-PROGRESS.md) | Progress log of the rebuild steps. |
| [`07-READINESS-GAPS.md`](07-READINESS-GAPS.md) | Production-readiness gaps and the design decisions taken for them. |
| [`23-LOAD-AND-SECURITY.md`](23-LOAD-AND-SECURITY.md) | Load and security verification of the whole stack. |
| [`inventory/`](inventory/) | Per-component inventories of the pre-rebuild code, verified against source. |
