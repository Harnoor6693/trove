## Decisions (settled by the owner on 2026-09-03 — do not re-ask)

| # | Decision | Answer |
|---|---|---|
| 1 | Architecture | **Modular monolith** — one JVM (`trove-core`) + Postgres, optional AI container |
| 2 | Tax engine | **Cut.** Ship a tax-time CSV/PDF export instead. No computed tax numbers |
| 3 | Jurisdiction/currency | **Canada and USA, both first-class.** Per-user setting chosen at onboarding. Others later |
| 4 | Exposure | **Public internet.** Full hardening in scope; recommend an external pen test before real bank data |
| 5 | Clients | **Web and Expo mobile both kept**, both production-ready |
| 6 | Household model | **One shared household ledger per install** (household scope in the P1 schema) |
| 7 | Mobile distribution v1.0 | **Sideload**: signed APK per GitHub release + TestFlight/AltStore; stores at v1.1 |
| 8 | Push notifications | **None until a direct APNs/FCM path exists** (no Expo relay). In-app inbox + local notifications in v1 |
| 9 | AI endpoint | **Per-user endpoints** — outbound-URL policy enforced per user; privacy statement must say so |
| 10 | Domain/TLS | **No public domain yet.** HTTP-01 default, DNS-01 documented for Cloudflare, no HSTS preload, Tailscale documented as the no-domain path |
| 11 | Repo visibility | **Stays private** until the maintainer decides otherwise. No branch protection; CI advisory; no public image registry |
| 12 | Security contact / pen test | **GitHub private vulnerability reporting; no paid pen test.** Internal adversarial security review on a staging stack; README states no external pen test |
| 13 | Licence | **AGPL-3.0 everywhere**, mobile included |

Assumptions made to satisfy "fully functional" without a hard resource cost (revisit only if the
owner objects):

- AI coach and LLM categorisation use a user-configured OpenAI-compatible endpoint (Ollama or
  cloud); off until configured.
- Receipt OCR uses the same vision-capable endpoint; PaddleOCR is cut. Without AI, receipts
  degrade to "attach image + manual fields".
- MinIO dropped (local-disk volume). Authentik dropped as a hard dependency: built-in local
  accounts (argon2id, optional TOTP) with optional OIDC.
- Native bank-notification listeners, IMAP/bank-email ingestion, and the plugin SPI are cut;
  SimpleFIN and OFX become packages of the core.
- Branch protection is unavailable (private repo, free plan → HTTP 403). The Dependabot
  auto-merge workflow is deleted instead; Dependabot runs monthly, grouped, majors ignored.

Machine: Apple M4, 10 cores, 16 GB, ~115 GB free. Rules: **one Maven build at a time**; always
`./mvnw clean`; Docker Desktop must be running for Testcontainers (`open -a Docker`).
